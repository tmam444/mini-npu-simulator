# Mini NPU Simulator

MAC(Multiply-Accumulate) 연산을 통해 입력 패턴이 십자가(Cross)인지 X인지 판별하는 Mini NPU 시뮬레이터입니다.

## 실행 방법

```bash
python main.py
```

실행 후 모드를 선택합니다:
- **모드 1**: 3×3 필터 2개(A, B)와 패턴을 직접 콘솔에 입력하여 판정
- **모드 2**: `data.json`에서 다양한 크기(5×5, 13×13, 25×25)의 데이터를 로드하여 일괄 판정

`data.json`은 `main.py`와 같은 디렉토리에 위치해야 합니다.

## 구현 요약

### 라벨 정규화 방식
`normalize_label()` 함수에서 `expected` 값(`'+'`, `'x'`)과 `filter` 키(`'cross'`, `'x'`)를 모두 표준 라벨(`Cross`, `X`)로 변환합니다. 이를 통해 데이터 소스에 따른 표기 차이를 제거하고, 일관된 비교가 가능합니다.

### MAC 연산 구현 개요
`mac_operation()` 함수에서 두 N×N 행렬의 같은 위치 값을 곱하고 모두 더하는 연산을 이중 반복문으로 직접 구현합니다. NumPy 등 외부 라이브러리를 사용하지 않습니다.

### 동점 처리 정책 (Epsilon)
`abs(score_cross - score_x) < 1e-9`이면 동점(UNDECIDED)으로 처리합니다. 컴퓨터의 부동소수점 표현 방식(IEEE 754)의 한계로 인해 수학적으로 같은 값이라도 미세한 차이가 발생할 수 있으므로, 직접 `==` 비교 대신 허용오차(epsilon) 기반 비교 정책을 적용합니다.

## 결과 리포트

### 실패 원인 분석

`data.json` 분석 모드(모드 2) 실행 시, 일부 테스트 케이스에서 FAIL이 발생할 수 있습니다. 발생 가능한 실패 원인은 다음과 같이 분류됩니다:

1. **동점 처리 규칙에 의한 FAIL (UNDECIDED)**
   - 예: `size_13_1` 케이스에서 Cross 필터 점수와 X 필터 점수의 차이가 `1e-9` 미만일 경우
   - 이는 필터 가중치가 의도적으로 동점에 가깝게 설계된 데이터에서 발생합니다.
   - epsilon 임계값을 조정하면 결과가 달라질 수 있으나, 부동소수점 안정성을 위해 `1e-9`를 유지합니다.

2. **라벨/스키마 불일치에 의한 FAIL**
   - `expected` 값이 `'+'`나 `'x'`가 아닌 경우 `UNKNOWN`으로 정규화되어 판정과 불일치
   - 패턴 키 형식이 `size_{N}_{idx}`를 따르지 않아 필터를 찾지 못하는 경우
   - 패턴의 실제 행렬 크기가 키에서 추출한 N×N과 다른 경우

3. **부동소수점 수치 오차에 의한 FAIL**
   - 데이터 값이 `0.3`과 같은 2진수로 정확히 표현할 수 없는 수인 경우
   - 대량의 곱셈/덧셈 과정에서 오차가 누적되어 예기치 않은 동점이 발생할 수 있음

현재 `data.json` 데이터 기준으로, 대부분의 케이스는 `normalize_label()`에 의한 라벨 통일과 `decide_result()`의 epsilon 정책 덕분에 PASS됩니다. 만약 FAIL이 0개라면, 이는 정규화와 epsilon 비교 정책이 모든 데이터 변이를 올바르게 처리하고 있기 때문입니다.

### 시간 복잡도 분석 (O(N²))

MAC 연산의 핵심은 N×N 행렬의 **모든 원소를 한 번씩** 순회하며 곱셈과 덧셈을 수행하는 것입니다.

- N=5일 때 연산 횟수: 5² = **25회**
- N=13일 때 연산 횟수: 13² = **169회**
- N=25일 때 연산 횟수: 25² = **625회**

크기가 5배(5→25) 증가하면 연산 횟수는 25배(25→625) 증가합니다. 이는 O(N²) 시간 복잡도의 전형적인 특성입니다.

실제 측정 결과에서도 N이 커질수록 연산 시간이 N²에 비례하여 증가하는 경향을 확인할 수 있습니다. 이것이 바로 실제 AI 모델에서 수백×수백 크기의 필터를 처리할 때 범용 CPU 대신 NPU(Neural Processing Unit)와 같은 병렬 처리 전용 하드웨어가 필요한 이유입니다.

| 크기 | 연산 횟수 (N²) | 예상 시간 비율 |
|------|---------------|---------------|
| 5×5 | 25 | 1x (기준) |
| 13×13 | 169 | ~6.8x |
| 25×25 | 625 | ~25x |
