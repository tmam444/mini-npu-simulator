# Mini NPU Simulator 학습 및 개발 플랜 (총 40시간 과정)

`subject.txt`의 요구사항과 `data.json`의 구조를 바탕으로, 40시간의 교육 과정에 맞춘 단계별 학습 및 구현 계획입니다.

## 1단계: 이론 학습 및 설계 (약 4시간)
* **AI와 MAC 연산의 이해**: CPU와 NPU의 차이점, AI에서 MAC(Multiply-Accumulate) 연산이 대량으로 필요한 이유 학습
* **알고리즘 설계**: 2차원 배열의 위치별 곱셈 및 누적합(MAC)을 외부 라이브러리 없이 구현하는 로직 구상
* **데이터 구조 분석**: `data.json`의 계층 구조(`filters`, `patterns`) 분석 및 키 추출 방식 설계
* **부동소수점의 이해**: 컴퓨터가 실수를 표현할 때 발생하는 오차를 이해하고, 허용오차(Epsilon, 예: `1e-9`) 기반 비교 정책 학습

## 2단계: 핵심 코어 모듈 구현 (약 8시간)
* **MAC 연산 함수 개발**: 두 개의 NxN 배열을 입력받아 MAC 점수를 반환하는 핵심 함수 작성
* **라벨 정규화 모듈**: `+`, `x`, `cross` 등의 다양한 입력 라벨을 `Cross`와 `X` 두 가지 표준 라벨로 변환하는 기능 구현
* **판정 모듈**: 두 점수의 차이가 `1e-9` 미만일 경우 `UNDECIDED` 처리하고, 그렇지 않으면 더 높은 점수의 라벨을 반환하는 로직 구현

## 3단계: 모드 1 (사용자 입력 처리) 구현 (약 6시간)
* **콘솔 I/O 처리**: 3x3 필터 A/B와 패턴을 콘솔에서 공백 기준으로 한 줄씩 입력받는 기능 구현
* **입력 검증 로직**: 행렬의 크기가 일치하지 않거나, 숫자가 아닌 값이 들어왔을 때 프로그램 종료 없이 안내 문구를 띄우고 재입력을 유도
* **시간 측정**: `time` 모듈을 활용하여 연산 구간의 소요 시간(ms)을 반복 측정(최소 10회)하고 평균을 구하는 로직 적용

## 4단계: 모드 2 (JSON 분석 시스템) 구현 (약 10시간)
* **파일 읽기 및 파싱**: `json` 표준 라이브러리를 활용해 `data.json` 로드
* **데이터 매핑 및 검증**: 
  - `size_{N}_{idx}` 형태의 패턴 키에서 `N`을 추출하여 필터 사이즈와 매칭
  - 패턴과 필터 크기 불일치 시 프로그램 중단 없이 해당 케이스를 `FAIL`로 기록
* **일괄 판정 시스템**: 5x5, 13x13, 25x25 케이스들을 순회하며 MAC 연산을 수행하고, 기대값(`expected`)과 판정 결과를 비교(`PASS/FAIL`)

## 5단계: 성능 분석 및 리포트 출력 (약 6시간)
* **콘솔 UI 구성**: 프로그램 시작 시 모드(1/2)를 선택하는 메뉴 구현
* **성능 분석 표 출력**: 입력 크기(3x3 ~ 25x25)에 따른 평균 연산 시간과 연산 횟수(N²)를 포맷팅하여 콘솔에 표 형태로 출력
* **최종 리포트 출력**: 전체 테스트 개수, 통과/실패 수, 실패한 케이스의 식별자 및 요약 사유를 출력하는 마무리 로직 작성

## 6단계: 보너스 과제 (선택) (약 4시간)
* **메모리 접근 최적화**: 2차원 배열 연산을 1차원 배열(길이 N²) 기반으로 평탄화하여 속도 향상 실험
* **패턴 자동 생성기**: 크기 `N`만 입력하면 NxN 십자가 및 X 패턴을 자동 생성해주는 유틸리티 함수 개발 및 성능 측정에 활용

## 7단계: 문서화 및 최종 점검 (약 2시간)
* **코드 리팩토링**: 가독성을 위한 함수 분리 및 주석 보강
* **README.md 작성**: 
  - 프로그램 실행 방법 안내
  - 실패 원인 분석 (예: 동점 처리 규칙에 의한 `FAIL`, 사이즈 불일치 등)
  - 성능 분석표를 바탕으로 한 시간 복잡도 `O(N²)` 증명 서술
